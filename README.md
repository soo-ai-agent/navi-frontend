# 나비 프론트엔드

백엔드가 반환한 질문과 적금 순위를 표시합니다. 답변은 브라우저 탭의 세션에 누적하며, 매 요청에 전체 답변을 보냅니다.

## 로컬 실행

먼저 `../backend`에서 가상환경을 활성화하고 `python main.py`로 서버를 실행합니다.
그다음 프론트엔드 디렉터리에서 실행합니다.

```bash
npm ci
npm run dev
```

Vite가 `/api` 요청을 `http://127.0.0.1:8000`으로 전달합니다. 백엔드 주소가 다르면 `.env.local`에
`VITE_BACKEND_URL=http://127.0.0.1:변경한포트`를 지정하고 Vite를 다시 시작합니다.
배포 환경에서는 같은 출처의 `/api` 경로를 백엔드로 전달하도록 웹 서버를 설정해야 합니다.

## 연결 흐름

`POST /api/v1/questions/next`에 `{}`로 시작합니다. 응답의 `question.key`를 그대로 사용해 답을 추가하고 전체 답을 다시 보냅니다.
숫자 답도 문자열로 보내며 건너뛰기는 `any`입니다. 서버의 `status`가 `done`이면 반환된 순위를 표시합니다.
은행별 질문 키, 금리 문자열, 우대 판정 결과를 서버 계약 그대로 받습니다.

뒤로 가서 답을 바꾸면 그 이후의 답을 제거하고 서버에서 다시 판정합니다. 오류가 나면 같은 누적 답으로 재시도할 수 있습니다.
상품 상세는 서버가 내려준 비교 결과와 우대조건 근거를 표시합니다.

전체 상품은 `GET /api/v1/products`로 조회하며 은행 카테고리를 좌우로 넘겨 볼 수 있습니다.
가입 상태·확인 금리·세전 예상 만기액은 누적 답변을 `POST /api/v1/products/compare`에 보내 조회합니다.
계산용 월 납입액과 기간은 URL로 전달하며, 원래 질문 답변이나 추천 결과를 덮어쓰지 않습니다.
금액과 가입 상태는 서버 결과를 표시하고, 미입력·확인 필요 상태를 0원 또는 가입 가능으로 바꾸지 않습니다.

## 검증

```bash
npm run build
npm run lint
npx playwright install chromium
npm run test:e2e
```

브라우저 테스트는 `../backend/venv/bin/python`을 사용합니다. 백엔드 의존성이 이 가상환경에 설치되어 있어야 합니다.
테스트 전용 FastAPI 서버(18000번)와 Vite(15173번)를 자동 실행하고 종료합니다.
고정 상품을 사용하는 실제 질문 API로 연결하며 운영 DB·금감원·LLM을 호출하지 않습니다.
별도 위치에서 실행하면 `E2E_BACKEND_DIR`로 백엔드 경로를 지정할 수 있습니다.
이미 설치된 Chromium을 사용할 때는 `E2E_BROWSER_PATH`로 실행 파일을 지정합니다.
실행별 HTML 보고서와 실패 추적은 `docs/reports/`에 저장됩니다.
